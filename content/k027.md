## JavaScript'te continue İfadesini Anlamak

"statement" kelimesinin "ifade" karşılığı kullanılmıştır. Örneğin "if statement" > "if ifadesi"

`break` ifadesi bir döngüden erken çıkmanıza olanak tanır. Ancak onun kuzeni olan `continue` ifadesi sıklıkla gözden kaçar. `continue`'nun nasıl çalıştığını ve kodunuzda etkili bir şekilde nasıl kullanılabileceğini inceleyelim.

### continue İfadesi Nedir?

`continue` ifadesi, bir döngüdeki mevcut iterasyonun geri kalanını atlar ve bir sonraki iterasyona geçer. Döngüden tamamen çıkan `break`'ten farklı olarak, `continue` sadece mevcut iterasyondaki kalan kodu atlar.

### Temel Kullanım

İşte `continue`'nun nasıl çalıştığını gösteren basit bir örnek:

```javascript
var i = 1,
    j;

for (j = 1; j <= 5; j += 1) {
    if (j === 2) {
        continue;
    }
    i += 1;
}

console.log(j); // 6
console.log(i); // 5
```

Bu örnekte, `j` 2'ye eşit olduğunda `continue` ifadesi çalıştırılır. Bu, döngünün o iterasyon için `i += 1` ifadesini atlamasına neden olur. Sonuç olarak, `i` 5 yerine sadece 4 kez artırılır.

### continue ile Label Kullanımı

`continue` ifadesi label'larla da kullanılabilir, bu özellikle iç içe döngülerde yararlıdır. İşte bir örnek:

```javascript
var num = 0,
    i, j;

outside:
for (i = 0; i < 10; i += 1) {
    for (j = 0; j < 10; j += 1) {
        if (i === 5 && j === 5) {
            continue outside;
        }
        num += 1;
    }
}

console.log(num); // 95
```

Bu durumda, dış döngüyü `outside` olarak etiketledik. `i` 5 ve `j` 5 olduğunda, iç döngünün geri kalanını atlamak ve dış döngünün bir sonraki iterasyonuna devam etmek için `continue outside` kullanıyoruz. Bu, `num`'un 100 yerine 95 kez artırılmasına neden olur.

### En İyi Uygulamalar

`continue` ile label kullanırken bazı en iyi uygulamaları takip etmek önemlidir:

1. Amacını açıkça belirten açıklayıcı label'lar kullanın.
2. Kod okunabilirliğini korumak için birkaçtan fazla döngü iç içe geçirmemeye çalışın.

Her zaman açıklayıcı label'lar kullanın ve birkaçtan fazla döngüyü iç içe geçirmemeye çalışın.

### Sonuç

`continue` ifadesi, özellikle label'larla kullanıldığında, döngülerinizin akışını kontrol etmek için güçlü bir araç olabilir. Ancak dikkatli kullanılmalıdır, çünkü aşırı kullanım anlaşılması ve bakımı zor kodlara yol açabilir.

`continue`'nun nasıl çalıştığını anlayarak, JavaScript kodunuzda daha verimli ve anlamlı döngü yapıları yazabilirsiniz.
